# honeymoon-data

Private storage for the Larch & Canyon itinerary app.

**This repository must stay private.** It holds hotel addresses, confirmation
numbers, receipts and personal photos.

    data/
      state.json     ← all itinerary state, rewritten by the app
      photos/        ← one .jpg per photo, uploaded by the app

Nothing here needs editing by hand. The app writes it through the GitHub API.

Do not enable GitHub Pages on this repository.
